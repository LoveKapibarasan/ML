EV Smart Charging
==================

Reinforcement-learning pipeline that trains a SAC agent to schedule EV
charging at minimum electricity cost, while guaranteeing the driver's
target state of charge is reached before departure.

See the repository `README <https://gitea.ai-charge.net/takanori.nagashima/ML#readme>`_
for architecture, data sources, and setup/running instructions, and the
`wiki <https://gitea.ai-charge.net/takanori.nagashima/ML/wiki/Home>`_ for
testing and CI notes. This site covers the Python API, generated from
docstrings.
